# Lata

Página de descarga de Lata, una herramienta para compartir archivos grandes directamente desde el disco de quien los envía.

Los archivos viajan cifrados y se descifran en el navegador de quien los recibe. La clave va en el enlace, después del `#`, y nunca se envía a ningún servidor. Esta página no guarda ni transporta archivos: solo los pide al equipo que comparte.

Para usarla hace falta un enlace completo enviado por quien comparte. Sin él, la página no hace nada.

Este repositorio se genera automáticamente; no se edita a mano.
